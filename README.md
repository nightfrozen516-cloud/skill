# 🚀 跨 AI 客户端本地技能库 (Agent Skills) 同步中心

这是一个跨 AI 客户端（**Claude Code**、**Codex** 和 **Antigravity**）共享的本地技能（Skills）托管和同步仓库。

无论您在哪里安装、修改了技能，本仓库的配置都可以实现多客户端（Claude/Codex/Antigravity）的**通用调用**，并通过 GitHub 仓库在**办公电脑**和**私人电脑**之间进行**双机无缝同步**。

---

## 📂 目录结构与操作指南

本仓库经过优化，隐藏了所有复杂的命令行操作。您**不需要打开终端输入命令**，直接双击运行根目录下的 `.bat` 批处理文件即可完成管理：

| 文件名称 | 操作说明 | 执行时机 |
| :--- | :--- | :--- |
| **`1-一键绑定与关联本台电脑环境.bat`** | 一键将本台电脑上的各 AI 客户端技能路径与共享目录进行绑定，并投影关联所有技能。 | 首次克隆此项目后运行一次 |
| **`2-同步更新到云端.bat`** | 自动检测本地技能文件的变更，生成提交并推送至您的 GitHub 私有仓库。 | 本地新增或修改技能后双击运行 |
| **`3-从云端拉取更新.bat`** | 从 GitHub 仓库拉取最新技能，并自动在本地重新建立所有客户端的映射关联。 | 在另一台电脑上使用前双击运行 |

*注：复杂的 PowerShell 同步脚本已收纳至 `tools/` 文件夹下，保持根目录极其干净整洁。*

---

## 💻 如何将技能同步到您的私人电脑？

只需在您的私人电脑上完成以下一次性配置，两台电脑即可实现技能库实时云端同步：

1. **在私人电脑上克隆技能库**：
   在私人电脑上新建或选择一个合适的目录，将您的私有仓库克隆到本地（推荐放到用户目录下）：
   ```bash
   git clone https://github.com/nightfrozen516-cloud/skill C:\Users\<您的私人电脑用户名>\.skills_shared
   ```
2. **一键初始化绑定**：
   进入克隆下来的 `C:\Users\<您的私人电脑用户名>\.skills_shared` 文件夹，**双击运行 `1-一键绑定与关联本台电脑环境.bat`**。
3. **日常同步**：
   * 在办公电脑上修改或添加了技能：双击运行 `2-同步更新到云端.bat`。
   * 在私人电脑上准备开始工作前：双击运行 `3-从云端拉取更新.bat`。

## 🛠️ 当前已为您安装的通用技能

这些技能已为您一键安装并暴露给所有客户端，AI 客户端会在需要时自动加载对应的 `SKILL.md` 指导它完成您的特定请求：

*   **🌐 网页抓取与访问 (`web-access`)**：教导 AI 如何在本地调用并控制浏览器、绕过安全屏障来深度抓取和阅读网页内容。
*   **✍️ 中文人性化改写 (`humanizer-zh`)**：教导 AI 以符合中文表达习惯、口吻自然、避免 AI 僵硬腔调的方式重写文本。
*   **🧠 Letta API 客户端 (`letta-api-client`)**：提供与 Letta 智能体平台进行对接、拥有长期记忆与自动化工作流控制的能力。
*   **⚙️ Prompt 强效优化 (`enhance-prompt`)**：自动帮助您将模糊、简单的 prompt 优化升级为结构严谨、细节充足的高质量提示词。
*   **☁️ Cloud Flow Wrangler 部署 (`wrangler`)**：辅助 AI 在本地控制 Wrangler 工具将静态网站、Workers 或服务一键部署到 Cloudflare。
*   **🐳 宝玉老师常用技能集 (`baoyu-skills`)**：
    *   `baoyu-image-gen`：高质量图像生成 Prompt 优化与执行。
    *   `baoyu-infographic`：自动根据文本生成精美的 SVG 信息图表和思维导图。
    *   `baoyu-markdown-to-html`：将 Markdown 转化为高保真、美观的 HTML 网页原型。
    *   `baoyu-translate`：高保真的学术与技术性中英互译。
    *   `baoyu-url-to-markdown`：快速抓取输入网址的内容并整理成结构清晰的 Markdown 笔记。
*   **🦌 字节跳动 Deer-Flow 自动化工作流**：
    *   `github-deep-research`：长上下文的 GitHub 深度研究与代码分析技能。
    *   `ppt-generation`：根据大纲自动生成精美的 PPT 演示文稿（基于 python-pptx）。
    *   `image-generation`：多模态图像生成控制。
